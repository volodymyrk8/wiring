# Очередь задач из приватной группы

В WIRING есть локальная доска черновиков задач. Она собирает сообщения из
формы поддержки и из одной выбранной Telegram-группы, убирает короткий шум,
помечает повторы и ставит оценку от 0 до 10. Сообщение ниже порога остаётся
в архиве, а кандидат ждёт ручного одобрения в `/admin`.

## Что уже работает

- `POST /admin/tasks/import-support` переносит существующие обращения из формы
  поддержки на доску.
- На доске можно одобрить, отклонить или отметить задачу готовой.
- Telegram-воркер читает только текст сообщений одной группы и не умеет
  отправлять, редактировать, пересылать или удалять сообщения.
- Повторный запуск безопасен: одно Telegram-сообщение и один тикет не создают
  две карточки.

## Одноразовое подключение на сервере

1. Создай API-приложение на `my.telegram.org` и задай на сервере переменные
   `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` и `TELEGRAM_SESSION_PATH` (например,
   `/var/lib/wiring/telegram-session`). Эти значения хранятся только на
   сервере. При ручном запуске сначала загрузи переменные окружения сервиса:

   ```sh
   set -a; . /etc/wiring.env; set +a
   ```
2. Войди локально аккаунтом, который уже состоит в нужной приватной группе:

   ```sh
   python3 telegram_ingest.py login
   ```

   Telegram попросит номер телефона, код и пароль двухэтапной проверки в этом
   терминале. Файл сессии создаётся по `TELEGRAM_SESSION_PATH` и должен
   оставаться на сервере с правами только для владельца процесса.
3. После входа выведи доступные группы и их числовые идентификаторы:

   ```sh
   python3 telegram_ingest.py list-groups
   ```

   Задай `TELEGRAM_GROUP_ID` для одной нужной группы и проверь разовый импорт:

   ```sh
   python3 telegram_ingest.py once
   ```

   Команда покажет число добавленных черновиков. Если группа ещё не задана,
   воркер завершится без подключения к Telegram.

4. Для регулярного чтения запусти `python3 telegram_ingest.py poll` под
   отдельным системным пользователем или менеджером процессов. По умолчанию
   проверка идёт раз в две минуты; интервал можно изменить переменной
   `TELEGRAM_POLL_SECONDS`.

Коды, пароль, API hash и файл сессии не нужно присылать в чат или помещать в
репозиторий. Чтобы изменить порог, задай `SUPPORT_TASK_THRESHOLD` (например,
`7.0`).
