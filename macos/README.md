# WIRING для macOS

Нативное приложение на SwiftUI (macOS 14+, Liquid Glass на macOS 26+). Работает с тем же API, что сайт и мобильные приложения: вход по токенам (`/api/auth/token`), токены в Keychain.

## Что есть
- Вход тем же аккаунтом, что на сайте и в телефоне.
- Боковое меню: Лента, Лайки, Чаты, Профиль (⌘1–⌘4), бейджи непрочитанного, счётчик на значке в Dock, значок в строке меню.
- Лента: большая карточка, фото листаются, ← пропустить, → нравится, пробел — следующее фото, I — профиль, перетаскивание карточки; «Отменить лайк»; окно мэтча; фильтры как на сайте (возраст, город, формат, диагнозы, вайб, «скрыть без диагноза»), сохраняются между запусками.
- Лайки: сетка, подстраивается под ширину окна; фильтры.
- Чаты: список с поиском + переписка рядом; отправка ↵ или ⌘↵, без дублей при повторе (`client_id`), «повторить» при ошибке, фото из файла, «Загрузить ранее», обновление каждые 5 с.
- Профиль человека: фото, теги, «Написать», «Пожаловаться», «Заблокировать».
- Свой профиль: редактор анкеты (фото — добавить, перетащить из Finder, сделать главным, удалить; основное, город с поиском, о себе, особенности, вайб, согласия; неполная анкета сохраняется черновиком), «Кому показывать мою анкету», уведомления на этом Mac, правила, выход. ⌘E — редактор.
- Уведомления macOS о новых сообщениях, когда окно не активно.

Архив решений и удаление аккаунта пока открывают сайт.

Токены: в подписанной сборке — защищённая связка ключей приложения (без системных запросов); в локальной ad-hoc сборке — файл в контейнере песочницы.

## Сборка
```sh
cd macos
xcodegen generate                      # project.yml → WIRING.xcodeproj (не коммитится)
open WIRING.xcodeproj                  # или из терминала:
xcodebuild -project WIRING.xcodeproj -scheme WIRING -configuration Debug -derivedDataPath build \
  CODE_SIGN_IDENTITY="-" CODE_SIGN_STYLE=Manual DEVELOPMENT_TEAM="" build
open build/Build/Products/Debug/WIRING.app
```
Для раздачи (TestFlight для Mac / App Store) — Release с подписью команды `G3T7684N3M`, bundle ID `date.wiring.mac`; запись приложения в App Store Connect нужно создать отдельно.

## Локальный сервер
```sh
defaults write date.wiring.mac apiURL http://127.0.0.1:5070   # или WIRING_API_URL=...
```

## Проверки
```sh
WIRING_API_URL=http://127.0.0.1:5070 WIRING_TEST_EMAIL=dev@wiring.test WIRING_TEST_PASSWORD=wiring-dev \
  build/Build/Products/Debug/WIRING.app/Contents/MacOS/WIRING --selftest
```
Проходит вход, профиль, каталог, ленту с фильтрами, лайки, чаты, переписку, профиль человека, ротацию токена и выход (`WIRING_TEST_WRITE=1` — ещё и отправку без дублей). Только для локального сервера с тестовыми аккаунтами.

`WIRING_SNAPSHOT_DIR=<любой путь>` с теми же переменными: приложение само входит, проходит по разделам, сохраняет снимки окна в `~/Library/Containers/date.wiring.mac/Data/tmp/wiring-snapshots/` и закрывается.
