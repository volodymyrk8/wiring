## Полное описание (до 4000)
WIRING — приложение для знакомств, где можно быть собой. Оно создано для нейроотличных людей и тех, кто ценит спокойное общение.

Что внутри:
• Анкета на твоих условиях: фото, короткий рассказ о себе, ярлыки по желанию. Никто не обязывает раскрывать больше, чем хочется.
• Лента без спешки: листай профили в своём темпе, лайк и пропуск — только явные действия.
• Взаимные симпатии: писать можно после взаимного лайка.
• Спокойные чаты: текст и фото.
• Безопасность: блокировка и жалобы на каждом профиле, удаление аккаунта в приложении.
• Светлая и тёмная темы.
• Только 18+.

Свои люди рядом. Можно быть собой.

## Сборка и подпись
- Загрузка в Play: **AAB** `../build/wiring-android-release.aab` (arm64-v8a, вне репозитория: подписанный артефакт не коммитим).
- APK для установки на телефон: `releases/wiring-1.0.0-android.apk`.
- Подписано **upload-ключом** `../signing/wiring-upload.jks` (вне репозитория, пароли в `../signing/keystore.env`). **Сохраните копию вне этого компьютера.** Включите Play App Signing при создании приложения: Google хранит ключ подписи, у вас остаётся upload-ключ, который можно сбросить через поддержку.
- Каждая новая загрузка требует большего `android.versionCode` в `mobile/app.json`.
- Сборка ограничена arm64-v8a (мало места на диске). Для полного набора уберите `-PreactNativeArchitectures`.

## Data safety (форма в Play Console)
Проверить с юристом.

| Данные | Собираются | Передаются третьим | Обязательные | Зачем |
|---|---|---|---|---|
| Имя, email | да | нет | да | Аккаунт |
| Фото | да | нет | нет | Профиль и чаты |
| Сообщения | да | нет | нет | Чаты |
| Данные о здоровье (нейротип, ярлыки) | да | нет | нет | Профиль и подбор, явное согласие |
| Приблизительное местоположение (город из списка) | да | нет | нет | Подбор |
| Идентификаторы устройства (push-токен) | да | нет | нет | Уведомления |

- Шифрование при передаче: да (HTTPS).
- Удаление данных: в приложении (Профиль → Удалить аккаунт). **Нужна ссылка на веб-страницу удаления аккаунта** для формы: проверить, есть ли она на wiring.date.
- Рекламных и аналитических SDK нет.

## Анкета рейтинга контента (IARC)
- Приложение для знакомств, пользовательский контент: да; романтические темы: да; итог 18+.
- Азартные игры, насилие, алкоголь: нет.

## Декларации
- Тип приложения: приложение, не игра. Реклама: нет.
- Целевая аудитория: 18+ (не для детей).
- Приложение для знакомств: политика Play требует модерации UGC — жалобы, блокировка, фильтр (есть).
- Финансовые функции, здоровье (как медицинское приложение): нет.
- Разрешения: камера, фото/медиа (выбор фото), уведомления (Android 13+).

## Тестирование перед публикацией
Новые личные аккаунты разработчика обязаны пройти **закрытое тестирование: минимум 12 тестировщиков в течение 14 дней подряд**, только потом доступен production. Организационные аккаунты освобождены. Проверить тип своего аккаунта.

## Заметки для ревьюера
1. Открывается на экране входа. Регистрация требует подтверждения 18+ и согласия на обработку данных.
2. Демо-аккаунт: создать на production (**сделать до отправки**), указать в разделе App access.
3. Жалоба и блокировка: карточка в ленте, профиль человека, чат. Удаление аккаунта: Профиль → «Удалить аккаунт».
4. Покупок нет, WIRING+ выдаётся в подарок.
